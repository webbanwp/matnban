# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅        |

## Reporting a Vulnerability

**Please do not open a public issue for security problems.**

لطفاً برای مشکلات امنیتی Issue عمومی باز نکنید.

Use one of these private channels:

- **GitHub private vulnerability reporting** (preferred): open this repository → *Security* tab → **Report a vulnerability**
- **Website contact form:** https://webbanwp.ir/contact-us/

Please include the plugin version, your WordPress and PHP versions, steps to reproduce, and the impact you see. Reports in Persian or English are both welcome. You will receive a response within 72 hours.

If the report is confirmed, a fix will be released as quickly as possible and credited in the changelog (unless you prefer to stay anonymous).
